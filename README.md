# 🔥 Project Phoenix v2

> **Rebuilding a college project into a production-grade Data Engineering Platform**

## 🚀 Mission

Transform an existing stock prediction project into a production-style data platform while developing the practical skills expected of a **Data Engineer 2 / Data Engineer 3**.

---

# 🗺️ Roadmap

## Phase 0 — Foundation & Architecture

### Objective

Design the platform before writing production code.

### Learning

- Data Engineering fundamentals
- Database design
- OLTP vs OLAP
- Project architecture

### Deliverables

- GitHub repository
- Project structure
- README
- Architecture diagram
- Dataset selection
- Engineering decision log
- Dashboard wireframe
- Bronze / Silver / Gold design

---

## Phase 1 — Advanced SQL & Data Engineering Theory

### Objective

Strengthen analytical SQL skills and core data engineering concepts.

### Topics

- Advanced SQL
- CTEs
- Window Functions
- Query Optimization
- Distributed Computing
- Batch vs Streaming
- Row vs Column Storage
- Data Lakes vs Data Warehouses
- File Formats
- Partitioning

### Deliverables

- SQL interview notebook
- Advanced analytical SQL practice

---

## Phase 2 — PySpark & Databricks Fundamentals

### Topics

- Spark Architecture
- DataFrames
- Transformations
- Actions
- Lazy Evaluation
- Partitions
- Databricks Workspace
- Clusters
- Notebooks

### Deliverables

- Spark ETL pipeline
- Databricks notebook
- CSV → Parquet pipeline
